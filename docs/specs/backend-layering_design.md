# 后端分层整理

采用按功能分模块的单体，不引入完整 DDD。接口路径、SSE 协议、向量维度、资料身份、切块参数、模型配置和历史路径保持现有行为。

- main：组装 FastAPI、中间件、路由和可选静态资源。
- router：HTTP 状态码、请求解析、响应和 SSE；不访问 SQL 或组装模型链。
- schemas：Pydantic 请求及公开响应约束，不作为数据库实体。
- chat/service：问答前置条件；rag/service：检索、历史与生成编排；rag/prompts：提示词。
- knowledge/service：导入与就绪状态；retriever：查询嵌入、文档转换；repository：知识表参数化 SQL。
- shared/database 与 schema：连接、嵌入空间兼容性、显式建表；history：现有文件会话存储。
- dependencies：集中创建应用服务；tests 使用依赖覆盖，不依赖旧入口内部实现。
- scripts：管理员 CLI；保留 api.py、database.py、import_knowledge.py 三个薄兼容入口，避免现有开发命令立即失效。

前端 API 和界面不变。仅维护私有开发副本与预览，不更新生产服务或博客路由。管理员资料、已有向量及历史不移动、不重建，原始文档不改。

安全核对：保留会话 ID 白名单、长度校验、参数化查询、来源字段白名单、通用错误响应和禁用上传；不输出凭据。身份认证、会话归属和限速仍属于公开上线前阻碍，开发预览继续仅监听 localhost。目录调整不能被视为完成这些能力。

验收：现有 API/RAG/隔离数据库测试全通过；导入预览仍为五份/63片段；既有版本重复导入跳过；开发预览健康、检索、SSE正常；旧线上服务仍停用。补充依赖覆盖、静态资源路径、兼容入口和历史/配置路径验证，避免 src 布局造成路径漂移。不在本次增加检索策略或改变已有参数。
