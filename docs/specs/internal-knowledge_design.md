# 内置扫地机器人知识库第一版

普通用户直接提问；管理员在命令行维护 knowledge/robot 中的 UTF-8 TXT。保留 Vue、FastAPI、LangChain、PostgreSQL/pgvector 和 SSE，关闭公开上传接口。

## 行为与边界

- 导入脚本默认仅预览文件及切块数，--apply 才调用嵌入模型并写数据库；相同版本重跑跳过，不在服务启动或提问时导入。
- 文档标识包含知识库命名空间、文件名及内容。检索同时限定命名空间和当前文件版本的哈希，旧上传资料及旧版本不参与回答，不删除旧记录。
- 数据库不可用、资料缺失或未全部导入时返回可读的未就绪状态；无检索结果时不调用生成模型。
- SSE 先发送检索参考资料，再发送回答、结束标记；参考片段是检索候选，并非对每个回答句子已经完成事实核验。
- 保留多轮历史，限制用于提示词的轮数；资料和历史不得充当系统指令，不记录完整提示词。
- 题库资料没有品牌授权、型号适用性或政策真实性保证。界面和回答不得把教程资料写成官方手册。对电池鼓包、冒烟等风险问题，建议停止使用并联系售后，不提供拆机或带电维修步骤。

## 安全核对

写入没有公开 HTTP 入口，只通过管理员 CLI。SQL 使用参数绑定；公开响应仅返回资料名、片段编号和片段正文，不泄露绝对路径、密钥和原始异常。Vue 使用文本插值，不渲染模型生成的 HTML。开发服务限 localhost；公开部署前仍需认证、会话隔离和请求限速，不将随机会话 ID 当作身份认证。

## 验收

验证上传返回 404；未配置/未导入返回 503；SSE 来源和中文文本正常传递，异常不泄露内部信息；空召回不生成；仅当前资料可检索；重导入跳过、更新版本不召回旧版；前端构建成功。使用隔离数据库和假嵌入测试事务及过滤，不使用现有生产库。真实模型的答案质量和耗时另以固定问答集实测，构建和假模型测试不能替代。
