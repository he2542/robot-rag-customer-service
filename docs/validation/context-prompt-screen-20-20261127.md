# 上下文提示词20题定向筛查

缩短引句并明确问题覆盖后，自动双轮共同通过率由8/20升至11/20。人工复核两处评分误判后的敏感性结果为9/20→10/20；候选保留为实验，继续处理维护信息漏答。

## 方法

从原300题选择12道原失败题、4道风险题和4道原通过对照；固定种子20261127，优先此前诊断题，运行前冻结。该集合用于定位问题。基线是原真实生成经过当前后处理的答案，候选新生成；两者均使用相同完整证据和后处理。生成日期不同，Qwen-Plus使用模型别名，未锁定权重快照。

候选只调整评测提示：逐项匹配用户明确需求，避免有直接证据时误判不足；引用改为6～180字的连续正文，控制完整JSON长度。线上提示词、召回、精排和证据构建代码均未改。

Qwen-Plus生成20次，温度0、seed20261111、最多1024输出Token。Qwen-Max按原300题的评分提示和必要要点，对新旧答案同批评分并交换顺序复评，共40次、每次最多2200输出Token。双方引用资料相同，在请求中共享一份完整context。主指标要求correct、supported且生成完整返回；原标签保留。
