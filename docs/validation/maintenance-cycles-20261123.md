# 维护周期校验测试

维护咨询中，回答可能引用了正确原文，却额外添加清洗或更换周期。维护周期校验比较结论与引句中的周期表达，发现新增周期时，使用对应的完整原文条目。

## 方法

对耗材、维护周期或频率类问题，提取结论与引句中的“每日”“每周”“3个月”“3-6个月”等表达；“至、～、-”按等价范围处理。替换要求引句唯一匹配一条完整编号原文，保留该条目的部件、环境和周期，并继续执行操作风险检查。

测试复用已有模型输出，通过实际 `RagService` 重放生成后处理。检索结果、模型消息与原始生成保持一致，执行时阻断网络。

## 结果

| 检查 | 结果 |
|---|---|
| 定向回归 | 7 项通过，覆盖新增周期、等价范围、条件保留、问题类型和风险过滤 |
| 本地后端测试 | 249 项通过，10 项数据库测试跳过 |
| 40 份输出回放 | 1 份改变，39 份不变；拖布、清洁刷和密封圈的 3 段新增周期改为原文 |
| 300 份输出回放 | 1 份改变，299 份不变；移除拖布结论中缺少引句支持的更换周期 |
| 输入与历史校验 | 两组回放的模型消息、来源和历史保存检查全部通过 |
| 风险回归 | 原有 10 道风险题输出不变 |
| 模型 API 调用 | 0 次 |

以上结果验证了已有输出的周期校验行为，整体回答准确率未重新评分。缺失部件名称、来源歧义或不完整引句不自动恢复；不同部件使用相同周期、适用条件混合等问题仍需语义校验。
