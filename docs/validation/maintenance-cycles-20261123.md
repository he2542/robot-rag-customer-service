# 耗材维护周期与原文对应

本轮修复维护咨询中“引句能定位，结论却额外加入其他周期”的情况。仅调整生成后处理，保持已恢复的提示、检索、精排和输入不变。

## 实现范围

耗材或维护周期/频率/节奏类问题中，提取结论与引句里的明确周期表达，如每周、每日、3个月、3-6个月；允许范围连接符“至、～、-”的等价排版。若结论新增引句没有的周期，且引句能唯一匹配来源中的一条完整编号行，则丢弃扩展结论，分别展示该原文的部件、环境和周期。

新增原文仍通过既有拆装、滴油、电气风险检查。无法完整定位、跨条目拼接或来源不唯一的引句不恢复。该检查只验证明确周期是否出现在引句中，不能判定全部语义、部件归属或同周期下的条件错误。

## 验证结果

- 7项定向用例通过：新增每3个月/每日/每周、等价范围、原有条件、普通故障题不改写和危险原文不恢复。
- 本地全套 **249通过、10项数据库测试跳过**。
- 40份冻结真实输出：消息、来源和历史 **40/40一致**；只改变b099实验版一份，其他39份逐字相同。拖布、清洁刷和密封圈3段新增周期被对应原文替换，未重新启用实验提示。
- 300份冻结输出：消息、来源和历史 **300/300一致**；只改变b099，其他299份逐字相同；10道原风险题不变。移除了拖布结论中未被该引句支持的“自动洗机型每3个月更换”扩展。
- 回放执行期阻断网络，新增付费调用 **0次**，不重用旧评分给改后的答案计分。

缺少部件名称的滤网引句仍被拒绝；不同滤网相同周期或不同来源条件混合的问题仍需单独校验。因此本轮确认的是新增周期清理，不宣布整道维护题或整体准确率已经通过。
