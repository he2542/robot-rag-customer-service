# 能力问句与APP语境修复

能力问句“能不能”“可不可以”现在按能力咨询处理，仍保留用户明确的禁止条件和已完成操作。APP卡住不会触发机械停机提示；同一问题另有轮组卡住或异响时，仍给出对应的停机边界。

## 效果验证

复用最新300题的原始生成、完整来源和冻结要点，不重新生成回答。仅7题可见文本改变，其余293题逐字不变，10道风险题不变；另68份独立历史生成在普通和原文展示模式下均保持不变，2份前置拦截记录未进入生成后处理。

全部7份变化由编码助手按相同要点和来源审读前后版本，并交换顺序复核：通过5/7→7/7，2题改善、0题退化；引用支持6/7→7/7。改善来自移除APP问题中的机械停机建议、恢复仅拖地问题中已匹配的完整操作条目。其余变化保留已有正确事实，改为完整原文展示。

此为受影响答案的离线增量复核，新增模型调用0次。原300题自动评分保持原记录；本次没有将7题结果换算为新的全量双轮模型通过率。证据相关性、原文操作范围及完整阶段验收继续单独处理，上下文实验仍默认关闭。
