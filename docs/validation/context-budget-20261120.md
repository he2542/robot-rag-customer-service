## 付费评测预算控制

`evaluation/budget.py`接入`evaluation.evaluate`及`evaluation.benchmark`的生成、质检、召回、回答、评分和复评阶段。独立评测进程内，在同步`requests`和`httpx`发送前预留调用次数、输入字节、最大输出Token与预计金额。失败不返还额度；SDK重试重新计数，底层连接重试在运行期间关闭。并发线程共享加锁计数，预算耗尽后停止新请求并取消排队任务。

调用上限1次时，第一次500或429响应仍消耗额度，第二次尝试在传输前被拒绝；并发16次尝试且上限3次时，只有3次到达替代传输。实际DashScope SDK的连接中断重试、文本Embedding及应用精排链路也通过替代传输验证，全部没有连接真实服务。

每个预算文件旁独占创建`.usage.json`账本，防止同一文件重复启动或被两个进程同时开启。每次发送前保存预留记录，账本不保存提示词、正文、密钥和授权头。未知模型、其他主机、富媒体、工具调用、异步及无输出上限的生成被拒绝。

输入使用请求字节及协议裕量作保守Token代理；金额按批准单价预留，是本次评测的估算配额。精确输入Token和账号真实账单另行核对。控制只覆盖当前两个入口及其同步HTTP出口，历史归档runner保留为证据；业务服务不启用该上下文。参数、单次预算格式与运行方法见[测试文档](../testing.md#请求级预算)。

## 复现

在`services/backend`执行以下离线命令：

```bash
python -m pytest -q

```

付费入口缺少显式参数时会拒绝执行；复现本报告不需要模型密钥或付费预算。源码、父结果、环境依赖与基线策略哈希保存在验收JSON中。第一阶段整体功能继续默认关闭，后续真实生成测试另行批准预算。
