# 操作边界修复：冻结回答离线验证

本轮达到两项目标：移除轴承滴油建议，取消纯过热保护功能咨询中的故障提示。仅修改生成后处理，保持`3897dd4`提示、检索、精排、来源和输入预算不变。

## 修改与结果

| 问题 | 修改前 | 修改后 |
|---|---|---|
| b196轴承卡顿 | 目标在前一分句，后一分句“可滴专用润滑油”未拦截 | 同一句中延续部件对象，移除该操作结论，保留其他可支持内容和售后提示 |
| b295保护功能咨询 | 遇到“过热”就追加停止使用充电 | 区分保护功能与已发生故障，保留原功能回答和引用 |
| 实际故障 | 已经烫手、过热或保护停机 | 继续提示停止使用充电，实际故障优先于功能词 |

滴油规则只针对已关联到电机/轴承的动作；禁止语句和动作前明确的专业执行角色保留。后面补一句联系售后，不能授权前面的用户操作。该规则在句号或换行处重置部件上下文。

- **20项定向用例通过**：分句滴油、同句稍后联系售后、否定与专业角色、普通清洁、功能咨询及实际故障并存。
- **本地全套231通过、10项数据库测试跳过**。
- 原20题两版共40份真实原始输出，使用各自归档提示和当前实际`RagService`回放，消息、来源和历史 **40/40一致**；仅b196、b295各两版，共4份可见回答改变，其余36份逐字相同。
- 旧300题使用当前恢复提示回放，消息、来源和历史 **300/300一致**；与回退前后处理相比，仅b196、b197、b295改变，其余 **297份逐字相同**。旧300题标注的10道风险题答案未变；b196在后续20题中另列为风险题。
- b197也涉及“轴承生锈、滴润滑油”，对应整条结论被移除，轮子更换及其他原文建议保留，并附专业售后提示；已审读该邻近改动。
- 执行期间阻断网络，新增生成、Embedding、精排、付费评分均为 **0次**。

该阶段确认具体建议被移除、误触发被取消，不重新使用旧分数为改后的答案计分。b196仍包含其他维护建议，本次没有宣布整道风险题已完全通过。条件合并、引句连续性以及其他安全语义问题继续独立处理。
