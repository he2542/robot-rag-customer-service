# 生成前证据整理：完整条目与审校排除

2026-11-15。开启条目整理后，现有 **63 个检索片段全部定位成功，5 条已标记问题原文被排除，254/254 条原本已存在且未被排除的目标证据保留**。Windows 与 Ubuntu/Python 3.10 的后端测试均为 90 项通过、10 项数据库测试跳过。

## 处理方式

```text
混合检索／精排前四
→ 校验文件版本并定位片段
→ 恢复相交的完整条目及章节条件
→ 应用版本绑定的审校排除
→ 保留来源顺序，统一编号
→ 同一份资料进入模型与 SSE 来源
```

完整条目从同版本 TXT 恢复，保留原文措辞、数值、否定词及适用条件。仍按原来最多 4 组来源组织，不另做条目排序。来源增加 `document_hash` 和 `source_spans`，后者记录原文起止行，支持排除中间条目后的多段定位。

匹配不可靠的片段保留原文，并记录回退分类；本次 63 个片段均无需回退。当前实现通过 `RAG_CONTEXT_ENTRIES_ENABLED` 独立开关控制，默认 `false`，可用于同候选对照。

## 审校记录

每条记录同时绑定文件名、完整文档版本、起始行和条目 SHA-256。记录针对已确认与当前回答策略冲突的操作建议，更新文档后需要重新核对。

| 记录 | 资料与条目 | 排除原因 |
|---|---|---|
| EV-001 | 扫地机器人100问2，第39条 | 要求用户自行插拔电池 |
| EV-002 | 扫拖一体机器人100问，第43条 | 要求用户检查并润滑拖布电机轴承 |
| EV-003 | 故障排除，第1条 | 另一处自行插拔电池的建议 |
| EV-004 | 故障排除，第89条 | 要求关闭碰撞保护 |
| EV-005 | 故障排除，第177条 | 要求用户处理内部电机轴承及更换电机 |

排除作用于完整条目。相邻条目保留；只召回问题条目的中间片段时，也会先恢复身份再排除。原 TXT、向量和数据库片段保持原样。
