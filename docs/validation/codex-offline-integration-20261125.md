## 隔离预检

评测使用官方原生CLI `0.172.0`、`gpt-6.2-sol`、low推理强度，沿用ChatGPT登录。运行前核验模型实际可见工具为空，任务使用临时工作目录、独立临时会话及只读沙箱。

工具隔离包含以下配置：

- 从账户模型目录选定模型，保留模型参数，通过本地目录文件关闭工具模式、命令、补丁和多Agent工具声明。
- 显式禁用每个已配置MCP服务器，并关闭网页、电脑操作、交互提问等功能；空配置表不足以清除已有配置。
- 固定评测基础指令，关闭项目文档加载；保留用户全局规则，核验其内容与哈希，计入输入预算。
- 读取管理配置要求的实际订阅提供方，本次为 `openai_http`；禁止切换API Key或自动回退Qwen。

初版只关闭功能开关，仍暴露模型工具；进一步定位到模型目录中的工具元数据和MCP配置合并。修正后预检返回 `model_visible_tools=[]`。前2个真实任务仍产生提供方配置诊断，因此被拒绝；按管理配置固定提供方后，剩余8个任务均验收成功。CLI诊断、工具事件和非法输出继续触发停止。模型、CLI二进制、适配器、规则、任务输入和Schema共同绑定缓存，配置变化时拒绝复用旧结果。

## 题集与结果口径

从[50题证据包](maintenance-independent-50-20261124.md)按类别、题号各选前4题，形成[冻结20题数据](codex-offline-20-20261125.json)。这是复用题集，用于模型接入和评分一致性比较。生成输入不含必要要点和旧答案，判分输入包含问题、资料、要点与待评答案。

3份有效生成对应n001、n031、n041，分别覆盖定时清扫、信息不足和电气风险。逐份审读确认：定时设置保留资料支持与来源编号；信息不足时要求补充条件；电气风险回答要求停止使用和充电并联系售后。

5份评分比较采用相同的已有Qwen回答（n001、n011、n021、n031、n041）。原Qwen-Max判定4/5通过，Codex判定5/5通过；唯一分歧n041来自通用安全提示是否有证据支持。冻结评分规则允许此类安全提示，两份判定均保留。80%是评审一致率，回答质量提升尚待20题独立比较；新生成结果未采用Codex自评作为质量结论。
