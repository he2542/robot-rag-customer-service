## 隔离预检

适配器保留现有订阅登录，移除继承的API密钥和桌面会话环境变量，使用临时工作目录并配置关闭命令、MCP、网页、电脑操作等工具。真实调用需要通过本地登录、模型目录和模型可见输入检查。

桌面内置CLI `0.169.0-alpha.11.1` 与独立官方CLI `0.172.0` 的输入探测均显示额外工具命名空间。独立安装未消除该现象，具体注入原因尚未确认。实现保留预检拒绝行为，未把登录成功或替代进程通过表述为真实模型接通。

后续接通条件：在实际执行环境中确认额外工具与继承指令均已隔离，再使用批准的任务限额运行生成和评分。现有10任务额度尚未消耗；20题质量比较的调用额度需单独确定。
