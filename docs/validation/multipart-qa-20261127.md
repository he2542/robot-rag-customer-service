# 并列提问的完整问答补全

用户同时询问设置位置、操作前提或参数时，回答现在可从唯一完整问答中恢复遗漏内容。只对完整原文引句生效，局部句子、重复来源、用户已说明的限制及危险操作不扩写。

## 修改

`complete_action_quote`增加完整问答来源定位。以多个疑问词识别并列需求，只有引句等于唯一编号问答的完整答案行（或完整问答），且已有回答缺少其中动作覆盖时，才输出完整原答案。跨多个条目、截断引句、已有用户限制与原安全检查保持原样。

本次修复两种明确漏答：删除旧地图的回答补齐清理反光物与移动障碍物；先扫后拖的设置回答补齐可自定义吸力与出水量。提示词、模型、检索和精排未改。
