# 上下文构建300题验收记录

完整首轮的回答通过率为 **87.00%→85.67%（−1.33个百分点）**，引用支持率为 **59.00%→93.67%（＋34.67个百分点）**。候选改善了引用，未达到回答质量验收要求，实验开关保持关闭，本轮不合并到主分支。

## 方法

复用原冻结300题、必要要点、召回候选和主分支`2c01297`的真实回答。候选保留完整条目、字节预算、来源身份和原生历史角色，增加条目导航，并展示经过字面核验的完整引句。系统规则与本轮JSON资料分开，模型和前端使用同一份sources；检索、精排和知识库未修改。

Qwen-Plus使用温度0、seed20261111、1024输出Token上限、非思考及JSON Object模式。300份候选中，280份新生成，20份复用完整请求哈希相同的已有响应。主分支回答生成于较早日期，比较包含生成日期及模型别名版本差异。

Qwen-Max在同批请求中独立评价两份回答，第二轮交换A/B顺序。沿用原评分提示，每次最多2200输出Token；每份回答提供自己的完整context。回答通过要求correct、supported且生成正常结束，危险建议判为不通过；引用支持单独统计。

## 失败定位与评分复核

- **证据相关性不足**：地毯增压问题选中了跨越厚地毯等相邻条目，未覆盖原问题的必要条件。完整证据提供后，模型仍可能选错条目。
- **能力问句误作禁止条件**：“能不能只拖地”命中禁止词守卫，完整引句里的安装和出水量步骤未展示。
- **软件语境误判**：APP卡住触发了机械故障停机提示，干扰正常软件处理建议。
- **原文操作范围未审清**：整段抽取仍可能带入拆解吸口组件等建议，资料未确认其是否属于用户可维护操作。自动评审未标出这一风险。

评审也存在漏读。潮湿停机题的候选已明确写出擦拭传感器及联系售后检测电路，两轮仍判缺少相关措施；耗材题首段包含全部指定周期，首轮漏读、交换顺序后通过；轴承题两轮对原安全豁免的应用不一致。风险子集、这些具体误判及原标签均保留，未用局部人工改分替换整体主结果。

本轮重点结论是：引句可追溯与回答完整性需要分别验收。下一次候选应先解决语境约束、证据选择和原文操作范围，再做小样本配对验证。
