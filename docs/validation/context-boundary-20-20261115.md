# 上下文消息分离：20 题配对诊断

2026-11-15。本轮确认：**带有效引用标记的回答从 3/20 增至 7/20；回答正确性提升尚未得到确认，输入 Token 和生成耗时增加。** 对照复用同一批精排结果，只改变系统规则与本轮资料的消息组织方式。

## 主要结果

| 指标 | 旧版：资料放入系统消息 | 新版：固定系统规则＋JSON 资料 | 差值 |
|---|---:|---:|---:|

| 回答自动通过：首轮 | 16/20（80%） | 18/20（90%） | +10 个百分点 |

| 含有效 `[S#]` 引用的回答 | 3/20（15%） | 7/20（35%） | +20 个百分点 |

自动通过要求同时满足“正确”和“有上下文支持”。两轮判分一致率为 39/40（97.5%）；首轮差值的配对重采样 95% 区间为 0～20 个百分点，复评为 0～15 个百分点。

**分数上涨不等于已确认的正确性改善。** 首轮新增通过的是 b022、b038；复评只剩 b022。新版 b022 仍建议自行插拔电池，评审却误称它明确禁止该操作。b038 的引用从不直接支持静音吸力结论的 S4 改为明确支持的 S1，是可核对的引用改善；旧回答的自动通过判定在两轮之间变化。
