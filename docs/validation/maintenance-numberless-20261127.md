# 维护条目缺少编号时的恢复与效果验证

当模型引句完整复制维护条目正文、仅省略列表编号时，现在能够恢复对应原文，并保留周期、否定条件和来源。条目必须唯一且完整；截断、歧义、错编号和危险操作继续拒绝。

## 修改与边界

`answer_policy.maintenance_entries`新增缺编号正文匹配。匹配只忽略已有的空白和加粗差异，再去除原文的起始列表编号进行完整比较；输出仍使用原始完整条目，不保留模型生成的摘要。模型提供了编号时继续要求原编号一致。

支持完整多行“问题＋答案”，不从局部句子推测条目。恢复后继续执行原引用定位及操作边界检查。提示词、检索、精排、模型、资料与API契约保持原样。
