# 限制类问题的原文条目恢复

本轮实现限制类咨询中的分条原文恢复：完整引句定位失败时，只有其中每一行都能唯一匹配当前来源中的完整编号条目，才分别输出原文及其来源，丢弃模型合并后的结论。

## 处理范围

- 仅用于使用限制、注意事项、适用条件、使用要求及维护要求类问题；故障排查保持原来的严格拒绝行为。
- 引句须含2～4行完整编号条目，整体仍受400字上限约束。每行需逐字匹配来源完整行，只容许既有排版差异；多来源歧义、缺字、改数字、改否定词和不完整条目均拒绝整组恢复。
- 恢复的是各条原文，保留型号、环境、否定词和数值；不重新采用模型拼接后的因果或条件结论。输出提示按各自条件分别参考。
- 恢复内容继续执行风险校验，额外禁止新增拆解、拉扯、插拔和滴油动作。有效的常规信息与专业提示可继续保留。
