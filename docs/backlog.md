# 开发路线图

本页说明当前能力和后续方向，不代表下列功能均已实现或已有交付日期。

## 已实现

- 管理员维护内置 TXT，预览/导入分离、重复版本跳过、事务写入。
- 当前资料版本隔离，排除旧版本和历史上传内容。
- 向量召回、中文 BM25、RRF 融合和检索模式切换。
- 多轮会话、SSE 回答、检索来源展示、请求中止和错误状态。
- 后端分层、前端组件拆分，以及 API/检索/数据库隔离测试。
- 首版固定问题集和逐题检索评测。

## 后续方向

| 方向 | 当前缺口 | 验证方式 |
|---|---|---|
| 资料质量 | 课程示例尚未完成型号、数值、政策和维修内容审校 | 核对官方资料，记录适用范围与冲突处理 |
| 检索评测 | 当前标签不穷尽，题集未覆盖全部文件 | 补齐相关性标注、独立问题和无答案问题 |
| 排序与召回 | 部分目标证据仍未进入候选，个别排名退化 | 区分漏召回与排序问题，再比较 rerank 等方案 |
| 引用支持度 | 编号过滤不能判断每个断言是否受证据支持 | 逐句核验支持度和引用完整性 |
| 公开部署 | 未实现应用级认证、会话归属和限速 | 跨会话访问、越权与限流测试 |
| 性能与成本 | 只有小样本顺序计时，未做并发或账单分析 | 固定负载测试、资源监测与实际用量统计 |
| 依赖维护 | 部分 LangChain 集成和历史封装发出弃用警告 | 迁移后回归协议、会话和检索行为 |

优先依据失败案例和评测结果选择下一项改动。rerank、查询改写与持久稀疏索引均尚未实现，不预先承诺会提升全部指标。
