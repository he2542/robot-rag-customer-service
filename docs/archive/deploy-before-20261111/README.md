# 历史部署配置

本目录保留早期上传式应用的 systemd、OpenResty、数据库与维护脚本。它们对应当时的目录、入口、数据模型和访问控制假设，不是当前内置资料版本的可直接部署方案。

其中曾使用反向代理提供 HTTPS Basic Authentication、API 限流与子路径托管。这些是历史部署层配置，不代表当前后端默认具备应用级认证和会话授权。

需要维护旧发布版本时，应使用与该版本一致的源码与配置，先核对环境和数据兼容性。当前运行和部署方式见 [部署说明](../../../deploy/README.md)，当前限制见 [安全说明](../../../SECURITY.md)。
