# v1.1.0：PostgreSQL 向量库与私有访问

这是 **v1.1.0 历史发布说明**。该版本仍采用上传式知识库和旧目录结构；当前主分支已使用管理员维护内置资料与混合检索，安装方式以 [README](../README.md) 为准。

## 版本变更

- 将知识库从 Chroma 迁为 PostgreSQL + pgvector，保存原文、向量、元数据及文档去重记录，并增加 HNSW 余弦索引。
- 文档与片段事务写入，支持并发去重和失败回滚。
- 数据库、聊天模型、嵌入模型及维度通过环境变量配置，检查嵌入空间兼容性。
- 健康检查包含数据库和模型配置状态。
- 提供子路径部署、systemd、PostgreSQL 扩展镜像及备份恢复说明。
- 当时的 OpenResty 配置提供页面/API 登录保护与请求限流；它不是当前应用默认开启的认证能力。

## 数据兼容性

旧 Chroma 数据不会自动读取、迁移或删除。升级存储前应备份，再导出或从原始资料重建，并核验检索结果。更换嵌入模型或维度需要重建向量或使用独立迁移方案，不能混用已有空间。

## 历史验证范围

该版本记录包含 12 项 API/数据库测试、前端构建，以及数据库、真实流式问答和代理认证的运行检查。这些属于当时发布环境的验证，不是当前主分支的测试结果或部署承诺。

版本配置见 [v1.1.0 部署文档](https://github.com/he2542/robot-rag-customer-service/blob/v1.1.0/deploy/README.md)，变更见 [v1.0.0...v1.1.0](https://github.com/he2542/robot-rag-customer-service/compare/v1.0.0...v1.1.0)。
