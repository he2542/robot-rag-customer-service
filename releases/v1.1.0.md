# v1.1.0 PostgreSQL 向量库与私有访问

将知识库从 Chroma 重构为 PostgreSQL + pgvector，并补充生产部署、私有访问与备份恢复说明。Vue 3、FastAPI、LangChain 和 SSE 流式问答继续使用。

## 本次更新

- 使用 PostgreSQL 存储原文片段、向量、元数据及文档去重记录，添加 HNSW 余弦检索索引。
- 上传按 SHA-256 去重；文档与向量在同一事务中写入，支持并发去重与失败回滚。
- 将数据库连接、聊天模型、嵌入模型和向量维度改为环境变量配置，检查嵌入模型与数据库配置是否一致。
- 健康检查增加数据库及模型配置状态；未配置模型密钥时显示“模型待配置”并禁用聊天与上传。
- 提供 `/robot/` 子路径部署、systemd 服务、1Panel PostgreSQL 的 pgvector 镜像构建与备份恢复说明。
- 提供 OpenResty HTTPS Basic 登录配置，覆盖客服页面、静态资源及所有 API；加入 API 限流和独立网站密码修改脚本。

## 从 v1.0.0 升级

本版本更换了存储后端，需要先配置 PostgreSQL + pgvector；旧 Chroma 数据不会自动读取、迁移或删除。已有知识库应先备份，再导出迁移或重新上传原始 TXT 文件，并核验检索结果。

1. 安装后端依赖，创建专用数据库及普通业务角色，由管理员在目标数据库启用 `vector` 扩展。
2. 参考 `.env.example` 配置 `DATABASE_URL` 和 `DASHSCOPE_API_KEY`。默认聊天模型为 `qwen3-max`，嵌入模型为 `text-embedding-v4`，向量维度为 1024。
3. 加载环境配置后运行 `python database.py` 初始化业务表，再启动后端与前端。
4. 生产部署参考 [deploy/README.md](https://github.com/he2542/robot-rag-customer-service/blob/v1.1.0/deploy/README.md)。网站登录保护由 OpenResty 配置提供；后端应只监听回环地址，避免绕过认证直接访问 API。

更换嵌入模型或维度需要重建知识向量；聊天历史仍保存在 `RAG_DATA_DIR` 下的文件中。真实密钥、密码和数据库备份均不包含在发布源码中。
