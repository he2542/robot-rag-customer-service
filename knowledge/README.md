# 内置扫地机器人资料

`robot/` 中的五份 TXT 复制自用户提供的黑马课程 Agent 示例资料，原件保留。仅供该学习项目检索，非品牌官方知识库。来源为本机 `Desktop/代码/AI大模型RAG与智能体开发_Agent项目/data/`。

- 故障排除、维护保养、选购指南、扫地机器人100问2、扫拖一体机器人100问。
- 本版未全文专业审校。不同条目的数字、适用型号和维护做法可能不一致；不要作为厂商承诺或维修操作依据。
- 仅 `robot/*.txt` 会被导入，提示词目录和 PDF 未混入知识库。
- 管理员修改或新增 TXT 后，运行 `backend/scripts/import_knowledge.py` 预览，再加 `--apply` 导入。变更的文件生成新版本，旧版本仍保留在库中但不会被当前客服检索。
- 文件删除会立即从当前检索范围排除；需恢复时还原文件。原件或数据库历史不被自动删除。
