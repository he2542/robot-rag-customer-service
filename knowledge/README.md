# 示例知识资料

`robot/` 包含五份扫地机器人课程示例 TXT：故障排除、维护保养、选购指南、扫地机器人 100 问和扫拖一体机器人 100 问。资料来自黑马课程 Agent 示例，用于演示知识导入和检索流程。

## 适用范围

资料不是品牌官方手册，尚未完成全文专业审校。不同条目的型号、数值、保修和维护建议可能不一致，不能作为厂商承诺或实际维修依据。真实客服应用应替换为有明确来源、授权和版本的业务资料，并经过专业审核。

## 维护方式

仅导入 `robot/*.txt`。文件必须是普通 UTF-8 TXT，单文件不超过 1 MB；程序不会导入提示词目录或 PDF。

在 `services/backend` 执行：

```bash
python -m src.cli import-knowledge
python -m src.cli import-knowledge --apply
```

第一条只预览；第二条调用嵌入模型并写入数据库。修改文件后重新导入，版本身份会随文件名和内容变化；旧版本保留但不参与当前检索。删除文件会将它移出当前检索范围，不自动删除历史数据库记录。

可通过 `RAG_KNOWLEDGE_DIR` 指定其他资料目录。更换资料后应同步更新题集并核验检索结果，不能沿用示例库的评测数字作为新资料的效果证明。
